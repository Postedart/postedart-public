# Posted.art Public Assets

This folder contains selected public-facing assets from the Posted.art App's `public/` directory, synchronized on 2026-10-03.

## Included assets

- `logos/`: the App's current PNG logo variants, including favicon, Apple touch icon, PWA icon, and wide logo sizes.
- `screenshots/`: the current Explore, Card, and Share screenshots, plus the connection walkthrough video.
- `favicon.ico`: the App favicon.
- `opengraph-postedart.png`: the App's social preview image.
- `manifest.json`: the App's web manifest reference.

These assets are a selected App snapshot. Third-party icons, fonts, and other runtime assets are outside this folder's scope.

The manifest's root-relative paths, `/explore` start URL, and icon and screenshot declarations belong to the App deployment. This folder is not a hosted app or an installable PWA by itself.

Future asset refreshes should use the App as the source of truth and update this synchronization date. Keeping App assets here does not imply that the website or native apps use identical asset sets.
