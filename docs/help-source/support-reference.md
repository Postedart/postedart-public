# Troubleshooting

Use the relevant task guide for normal steps. If something behaves unexpectedly, note your client, device and the action that triggered it so support can distinguish an editing problem from a connection or saving problem.

## Text moves or wraps unexpectedly while typing

Longer messages and line breaks can sometimes produce small position changes or unexpected wrapping in the Write editor.

Finish editing with the **checkmark**, then inspect the message on the canvas. Check the appearance again on Share before creating the Postcard. Finishing editing is a way to review the result, not a guaranteed fix for every typing problem.

If the result is still wrong, describe:

- Your client: iOS, Android, web/PWA, Telegram or Farcaster.
- Your device and browser or host app, where relevant.
- Whether the issue is movement, unexpected line breaks, missing text, freezing or failure to save.
- The steps that reproduce it. A screenshot can help; remove private information before sharing one.

Do not assume missing text or a crash is simply harmless editor movement. Avoid resetting, refreshing or signing out while you still need an unsaved design: those actions can lose working state. See [Write](write.md) for editing and saving options.

## Wallet connection or payment problems

For connection and signature requests, follow [wallet connection support](wallet-connection.md#wallet-connection-and-signing-support). Record the wallet, network and exact step that failed. Never share recovery words or private keys.

If a wallet payment completed but the Postcard did not appear, reconnect the same wallet promptly and check Account before paying again. See [payment recovery](share.md#payment-completed-but-the-connection-was-interrupted).

## Contact support

Use the [FAQ contact section](https://github.com/Postedart/postedart-public/blob/main/docs/faq.md#how-can-i-contact-postedart) if the task guides do not resolve the problem. Include the relevant steps and visible error. For a payment issue, include the transaction receipt and network rather than wallet credentials.
